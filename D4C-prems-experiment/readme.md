# D4C PReMS Experiment

## Requirements
- Docker Desktop
- VS Code + Dev Containers extension

## How to Run
1. Open this folder in VS Code
2. Click Reopen in Container when prompted
3. Run `python run_all_pipeline.py`
4. To run the JaCoCo coverage pipeline, run `python3 run_all_jacoco_pipeline.py`

## Output
- PReMS results are written to `d4c_prms_results.csv`
- JaCoCo results are written to `d4c_jacoco_results.csv`
